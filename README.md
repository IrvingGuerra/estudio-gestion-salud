**Ábrelo en el celular:** https://irvingguerra.github.io/estudio-gestion-salud/

| Archivo | Qué es |
| --- | --- |

| `quiz.html` | 43 preguntas de opción múltiple con explicación al instante; guarda en el navegador las que falles |
| `guia-gestion-salud.pdf` | La misma guía para imprimir (tamaño carta, 29 hojas) |
